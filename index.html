System Architecture & Capabilities

Built for classroom demonstrations, final-year engineering presentations, and modular hardware integration.

Sensor Telemetry Simulator

Generates 3-axis accelerometer values (X, Y, Z), resultant G-force, and speed fluctuations with automated cleanup timers.

Accident Detection Logic

Triggers emergency warning beacons when simulated impact exceeds 4.0G, creating timestamped incident records and audio alarms.

Leaflet GPS Mapping

Captures real browser coordinates via HTML5 Geolocation API with graceful fallbacks and direct links to Google Maps.

Emergency Contact Triage

Click-to-call links and prefilled distress SMS generators for primary contacts and municipal paramedic dispatchers.

Analytics & CSV Exports

Dynamic Chart.js visualizations calculate trends, severity ratios, and rider breakdowns directly from persistent records.

Firebase & Local Storage

Zero configuration required out of the box with LocalStorage; pluggable Firebase Auth & Cloud Firestore adapter ready.
